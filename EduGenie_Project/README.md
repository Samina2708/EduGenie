# EduGenie Project Folder

This folder organizes the supplied EduGenie application into the eight project phases requested.

1. Brainstorming and ideation
2. Requirement analysis
3. Project design
4. Project planning
5. Project development — the supplied application is in `05_Project_Development_Phase/application/`.
6. Project testing
7. Project documentation
8. Project demonstration

The phase README files summarize the existing source or suggest planning activities. They do not represent completed approvals, test runs, or demonstrations unless explicitly stated. Start with the application README for setup and run instructions. Keep your Gemini API key private; the archive does not include a configured key.
