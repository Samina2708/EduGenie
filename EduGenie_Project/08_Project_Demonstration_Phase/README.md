# Project Demonstration

## Suggested walkthrough
1. Introduce EduGenie and its learner-focused purpose.
2. Show the home page and explain the five learning tasks.
3. Demonstrate a question answer and a beginner-friendly explanation.
4. Generate a short quiz, summarize text, and request a learning path.
5. Show the health check and explain how credentials remain server-side.

## Before presenting
- Install dependencies and set a valid Gemini API key in a private local `.env` file.
- Confirm internet access and the service responds.
- Prepare sample prompts and a fallback screenshot/demo recording if the AI service is unavailable.
