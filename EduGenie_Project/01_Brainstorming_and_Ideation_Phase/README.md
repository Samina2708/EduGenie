# Brainstorming & Ideation

## Project concept
EduGenie is an AI-assisted learning web app. The supplied source already implements Q&A, beginner-friendly explanations, short multiple-choice quizzes, text summaries, and personalized learning recommendations using Google Gemini.

## Ideas to explore
- Let learners choose a topic and request the learning task they need.
- Keep answers understandable for beginners and return structured quiz questions.
- Add reliable empty-input validation, useful service error messages, and a health check.
- Future ideas: saved learning history, difficulty settings, accessibility improvements, and teacher-created topic packs.

These are project ideas and proposed extensions, not claims that every feature is implemented.
